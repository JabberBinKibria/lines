# lines

**lines** is a simple 2D game built with the [Godot Engine](https://godotengine.org/) (primarily using GDScript). You can clone or download the repository and open it in Godot to play, inspect, or customize the game.

## Project Overview

- **Engine:** Godot Engine (`project.godot`)
- **Primary Language:** GDScript
- **Core Files & Folders:**
  - `player.gd` — Player movement and gameplay logic
  - `scene/` — Game scenes and level layouts
  - `sound/` — Sound effects and audio assets
  - `04B_30__.TTF` — Pixel/arcade font asset
  - `default_env.tres` — Default environment settings
  - `export_presets.cfg` — Export configurations
